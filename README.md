# AI SaaS Image Generation Platform

A full-stack AI-powered SaaS application that generates images from text prompts using modern AI APIs and the MERN stack.

---

## 🚀 Features

* Secure JWT Authentication
* AI Text-to-Image Generation
* Image History System
* Responsive User Interface
* RESTful API Integration
* Real-Time Image Preview
* Optimized Backend Performance

---

## 🛠️ Tech Stack

### Frontend

* React.js
* CSS
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Authentication

* JWT (JSON Web Token)

---

## 📂 Project Structure

```bash
client/   -> Frontend
server/   -> Backend
```

---

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Monukumawa/Ai-saas-image-generation-platform.git
```

---

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

### Backend Setup

```bash
cd server
npm install
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file inside the server folder and add:

```env
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
AI_API_KEY=your_api_key
```
